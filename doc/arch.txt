Sol R1

CPU SPECS:
- 8-bits word
- 8-bits numbers support
- 8-bits registers
- 8-bits I/O port

- RISC Single-Cycle FDE
- 256 adresing and 65536 with paging
- Program lives in RAM
- Low cust CPU
- PC inc +1 after instruction

- Clock 3 stages:
- clock-up  is the stage on the decoder works to prepare path
- clock-on  the signal clk of decoder is emited, this stage it can be small
- clock-off stage of the pc inc +1

- Easy Decoder:
- path-decoder gets the entry and active the path for make the instruction
- op-decoder   emit the signal CLK in components

SIGNALS PIN:
- receive_port (external dispositive send a pulse here to say re send info in input buffer)
- send_port (cpu sends a pulse to say the program put data in output buffer)

ALU FLAGS:
- negative: if MSB is 1
- zero: if all bits is 0
- positive: if not negative and not zero
- overflow: MSB carryout XOR MSB carryin
- carry: if MSB carryout
- notcarry: if not msb carryout
INPUT FLAGS:
- input: ON if cpu receive from dispositive a pulse in pin receive_port
