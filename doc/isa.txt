ALU REAL FLAGS:
- negative: if MSB is 1
- zero: if all bits is 0
- overflow: MSB carryout XOR MSB carryin
- carry: if MSB carryout
ALU CALCULATED FLAGS:
- positive: if not negative and not zero
- notzero: if not zero
INPUT FLAGS:
- input_ready: ON if cpu receive from dispositive a pulse in pin receive_pin

REGISTERS: - HEX Code | Name | Mnemonic
0 Accumulator    (ACC)
1 Base           (BASE)
2 Counter        (COUNT)
3 Ram-Page       (RP)
4 Ram-Addr       (RA)
5 Stack-Page     (SP)
6 Stack-Addr     (SA)
7 Pointer-1-High (P1H)
8 Pointer-1-Low  (P1L)
9 Pointer-2-High (P2H)
A Pointer-2-Low  (P2L)

F Flag           (FL)

REGISTER FLAGS (in byte positions):
0 - negative
1 - zero
2 - overflow
3 - carry

- RFP = Ram full Pointer   (RP + RA) - Used for store 16bits addr for copy in pc
- SFP = Stack full Pointer (SP + SA)
- P1F = Pointer 1 (High + Low)
- P2F = Pointer 2 (High + Low)

- Letter X means opcode is anywhere
- I reffer to regs with Mnemonic/Hex code
- 1 to 3: Imediate
- 4 to 7: Ram
- 8 to 9: Mov
- A to C: Get
- D     : Alu
- E     : Input, Misc and hardware aceleration instruction
- RX = REG X (this X is REG table hex value)

ISA:
Family 0:
X - NOP

Family 1:
X - IMMH X - Load X in Imediate buffer High
Family 2:
X - IMML X - Load X in Imediate buffer Low
Family 3:
X - IMM X - Load Imediate buffer value in RX and Imediate buffer dont clean

Family 4:
X - LOADSFP RX - Load RAM[SFP] in RX
Family 5:
X - STORESFP RX - Store RX value in RAM[SFP]
Family 6:
X - LOADP1 RX - Load ram value P1F in RX
Family 7:
X - STOREP2 RX - Store RX value in ram P2F

Family 8:
X - MOVA RX - Mov ACC value to RX
Family 9:
X - MOVC RX - Mov COUNT value to RX

Family A:
X - AGET RX - Mov RX value to ACC
Family B:
X - BGET RX - Mov RX value to BASE
Family C:
X - CGET RX - Mov RX value to COUNT

Family D:
0 - SUM     - ACC = ACC + BASE   (Update all alu flags)
1 - SUB     - ACC = ACC - BASE   (Update all alu flags)
2 - SHL     - ACC = ACC << 1     (Update only negative and zero alu flags) - EX 10010111 to 00101110
3 - SHR     - ACC = ACC >> 1     (Update only negative and zero alu flags) - EX 10010111 to 01001011
4 - NOT     - ACC = NOT ACC      (Update only negative and zero alu flags)
5 - AND     - ACC = ACC AND BASE (Update only negative and zero alu flags)
6 - OR      - ACC = ACC OR BASE  (Update only negative and zero alu flags)
7 - XOR     - ACC = ACC XOR BASE (Update only negative and zero alu flags)
8 - JMP     - JMP to RFP
9 - JNEG    - JMP to RFP if negative flag
A - JZ      - JMP to RFP if zero flag
B - JPOS    - JMP to RFP if positive flag
C - JO      - JMP to RFP if overflow flag
D - JC      - JMP to RFP if carry flag
E - JNZ     - JMP to RFP if notzero flag
F - JINP    - JMP to RFP if input_ready flag

Family E:
0 - INC RFP
1 - DEC RFP
2 - INC SFP
3 - DEC SFP

4 - INC P1F
5 - DEC P1F
6 - INC P2F
7 - DEC P2F

8 - INC COUNT (Update only negative and zero alu flags)
9 - DEC COUNT (Update only negative and zero alu flags)
A - MOV1    - Move P1F to RFP
B - MOV2    - Move P2F to RFP

C - SEND    - Move ACC to output_data buffer and send a pulse in pin send_pin
D - RECEIVE - Move input_data buffer to ACC (and set off flag input_ready)
E - CLA     - Clear ALU (base, acc and flags)
F - PC      - Copy PC to RFP

Family F:
X - Halt

WARNING:
- After an instruction, pc inc +1
