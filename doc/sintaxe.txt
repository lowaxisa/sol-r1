--- Expressions:
CONCAT: sintaxe ( CONCAT STR_A STR_B )
for ex: ( CONCAT A B ) - AB

AT: sintaxe ( AT STR INDEX )
for ex: ( AT HELLO 1 ) - E

FILTER: sintaxe ( FILTER STR LIST DEFAULT )
for ex: ( FILTER AX AX BX CX ERR ) - AX
for ex: ( FILTER DX AX BX CX ERR ) - ERR

ESPACE: sintaxe ( ESPACE )
for ex: ( CONCAT A ( ESPACE ) ) - 'A '

ENDLINE: sintaxe ( ENDLINE )
for ex: ( CONCAT A ( ENDLINE ) ) - 'A\n'

UPPER: sintaxe ( UPPER STR )
for ex: ( UPPER hello ) - HELLO

LOWER: sintaxe ( LOWER STR )
for ex: ( LOWER HELLO ) - hello

suport aninhed expressions example:
